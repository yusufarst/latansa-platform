# Design System

## 1. Overall Direction
The application should feel comparable to a high-value enterprise SaaS/product platform.
- **Aesthetic**: Restrained, modern, premium.
- **Avoid**: Generic AI-dashboard looks, excessive gradients, excessive glassmorphism, excessive rounded cards, excessive animation, decorative UI that slows operational work, inconsistent component patterns.

## 2. Public Catalog Principles
- Premium, conversion-oriented, trustworthy, visually polished.
- Excellent high-quality product cards.
- Premium product detail pages.

## 3. Internal Application Principles
- Speed, clarity, and operational efficiency first.
- Professional data tables.
- Excellent forms.

## 4. UI Rules
- **Typography**: Strong, modern typography. Clear information hierarchy.
- **Spacing**: Excellent, consistent spacing.
- **Color Strategy**: Do not invent a complex brand palette yet. Keep it adaptable until actual LATANSA branding/assets are available. Use subtle, professional tones.
- **Radius**: Restrained corner radius (e.g., standard shadcn/ui defaults).
- **Cards & Tables**: Clean, border-based or subtle shadow separation.
- **Forms & Buttons**: Clear affordances, accessible contrast.
- **Dialogs/Drawers**: Used for contextual workflows (e.g., quick edits, stock movements).
- **Navigation**: Intuitive, supporting deep hierarchies for product/inventory management.
- **Mobile Rules**: Responsive/mobile-specific UX required for all public pages and essential internal workflows.
- **Status Indicators**: Clear badges/colors for stock status, order status, QC status.
- **Charts**: Clean, data-focused visualization without unnecessary decoration.

## 5. Interactions & States
- **Micro-interactions**: Subtle, enhancing feedback without causing delays.
- **States**: Proper loading states, skeletons, empty states, and error states must be implemented.
- **Accessibility**: Hover/focus states and accessible keyboard behavior are mandatory.
- **Search**: Useful command palette/global search patterns for rapid navigation.
