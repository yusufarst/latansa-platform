---
name: premium-ui
description: Design and implement premium LATANSA public catalog and internal application UI with consistent enterprise-grade UX and responsive behavior.
---

- Follow @/docs/05-DESIGN-SYSTEM.md.
- Ensure a premium but restrained design.
- Use strong hierarchy and typography.
- Ensure excellent spacing.
- Reuse shared components.
- Use consistent design tokens.
- No generic AI dashboard appearance.
- Avoid excessive gradients.
- Avoid excessive glassmorphism.
- Avoid excessive rounded cards.
- Avoid unnecessary animation.
- Public pages optimize trust and conversion.
- Internal pages optimize operational speed.
- Excellent table/form UX.
- Responsive desktop/tablet/mobile behavior.
- Use proper loading/skeleton states.
- Use proper empty states.
- Handle errors gracefully.
- Include hover/focus states.
- Ensure keyboard accessibility.
- Mobile UX must be intentionally designed, not merely compressed desktop.
- Use official LATANSA branding assets when available.
